Ranking Visible Content by CTR Review Priority

Abdelrahman Mohamed · Machine Learning Track · github.com/abdelrahmanmohamed05/FlyRank-AI

§Abstract

Search teams have limited time to manually review content for click-through-rate issues, so a ranked queue that surfaces the most promising review candidates first has direct operational value. This paper asks whether content likely to under-capture clicks in a future month can be identified using only information available before that month.

Using pseudonymized client/content-level Search Console aggregates from the FlyRank internship warehouse, five pre-outcome features from a February 2026 window are used to predict March 2026 CTR underperformance. A logistic regression model is compared against a transparent rule-based baseline on an identical, client-grouped held-out split. The result is observational and decision-support only — it ranks a review queue, it does not establish a causal effect on click-through behavior.
